
# 毕达哥拉斯树：一场由点击决定的生长游戏

**Pythagoras Tree — One Button, Infinite Possibilities**

## 项目简介

这是一个基于毕达哥拉斯树（Pythagoras Tree）几何结构设计的单按钮小游戏，使用 MATLAB 开发。

项目的灵感来自 MathWorks 举办的 **MATLAB One-Button Game Mini Hack**。这项活动鼓励参与者利用 MATLAB 开发只需一个按钮即可操作的小游戏。

比赛主页：[MATLAB One-Button Game Mini Hack](https://ww2.mathworks.cn/matlabcentral/communitycontests/contests/10/entries?utm_source=chatgpt.com)

我最初只是想尝试：如果把一个经典的数学分形结构变成一个可以由玩家亲自构造的游戏，会是什么样子？

## 设计思路

毕达哥拉斯树是一种通过不断在正方形上构造直角三角形和新的正方形而形成的分形图案。

最初的设想是：让三角形的直角顶点沿圆周运动，使两条直角边的比例不断变化。玩家可以在任意时刻点击，锁定当前角度，并让图案向外生长一层。

如此反复，玩家便可以逐步构造出属于自己的树。

在实际设计和试玩过程中，我又逐渐加入了一些机制：

- **角度变化：** 将生长角度限制在 30°～60°，避免后期产生过于细小的分支。
- **同步生长：** 设计双节点和四节点两种模式，减少逐个操作的繁琐。
- **随机选择：** 不再按照固定顺序生长，而是随机选择分支组，让每次游戏都可能产生不同的树形。
- **尺寸阈值：** 当正方形边长小于初始边长的 20% 时，停止继续分支。
- **碰撞检测：** 如果新生成的正方形与已有图形发生重叠，游戏失败。

我希望保留数学结构本身的美感，同时让玩家通过简单的操作获得一定的创造自由。

## 游戏玩法

| 操作 | 功能 |
|---|---|
| 鼠标左键 | 让当前选中的分支生长 |
| `2` | 双节点同步模式 |
| `4` | 四节点同步模式 |
| `R` | 重新开始 |
| `Q / Esc` | 退出游戏 |

**游戏结束条件：**

- 新生成的正方形发生重叠：游戏失败。
- 所有分支均达到最小尺寸阈值：游戏完成。

## 技术实现

- MATLAB 图形界面与交互回调
- 参数化几何构造与向量运算
- 随机分支选择与同步生长
- 分离轴定理（SAT）碰撞检测
- 动态角度控制与图形可视化

## 运行方法

使用 MATLAB 打开 `game3.m`，在命令窗口输入：

```matlab
game3
```

无需额外工具箱。

## 项目感想

这个项目从一个简单的数学图形出发，逐渐发展成了一个具有随机性、交互性和明确游戏规则的小作品。

对我而言，有趣的不仅是最终生成的树形，更是如何将一个数学结构转化为一套可交互的规则：如何定义生长，如何处理碰撞，如何平衡随机性与可控性，以及如何让简单的操作产生丰富的结果。

**每一次点击，都是对下一段生长路径的一次选择。**
